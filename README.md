# React Admin Starter

A lightweight, reusable React admin starter. The application foundation will be adapted from [satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin).

**Status:** repository initialized; implementation will be introduced through reviewed pull requests.

## Goals

- React + TypeScript + Vite + shadcn/ui + Tailwind CSS
- TanStack Router, Query and Table
- Chinese-first admin UX, configurable branding and themes
- Mock-first development and an OpenAPI-oriented service boundary
- Reusable auth, RBAC, CRUD, file-upload, audit-log and error-handling patterns
- Framework-agnostic REST backend integration (GoFrame, Gin, and others)

We will start with the `v0.1 Foundation` milestone: import and pin the upstream baseline, establish project conventions, configure CI and simplify demo content.
